---
name: commit-and-push
description: Write a concise commit message about current changes the push that commit.
---

1. Switch to plan mode
2. Write the commit message about $ARGUMENTS or the current changes according to the project instructions — **use conventional commits / commitlint syntax** (e.g. `feat:`, `fix:`, `chore:`, `refactor:`) as enforced by the pre-commit hook
3. Wait for the supervisor to accept the commit message
4. Make the commit
5. Push that commit
